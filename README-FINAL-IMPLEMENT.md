## Deploy
Extract this ZIP over your existing local GitHub repo folder with `-Force`.

Then run:
git status
git add .
git commit -m "Implement mobile Home fixes and live email forms"
git push origin main

## One-time form activation
After GitHub Pages finishes building:
1. Open the live website.
2. Submit one test form.
3. Check osamaghaffar001@gmail.com for the FormSubmit activation email.
4. Click the confirmation link.
5. Submit another test lead and confirm it reaches the inbox and redirects to thank-you.html.
