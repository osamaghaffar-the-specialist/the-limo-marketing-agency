**Validated:** 2026-10-10  
**Property:** https://osamaghaffar-the-specialist.github.io/the-limo-marketing-agency/  
**Purpose:** lock keyword ownership before any new production URL is created, prevent cannibalization, and prioritize queries that can produce qualified limo / chauffeur / taxi operator leads.

## Research State & Data Rules

- Volume / KD / CPC are preserved only where they were explicitly verified in the project's Semrush snapshot already captured in the project handoff.
- `—` means the metric was not independently verified in that snapshot and is intentionally not guessed.
- US CPC values are USD (`$`). UK CPC values are GBP (`£`).
- Live SERPs were spot-checked again on 2026-10-10 to validate **intent, competitor type and page-format fit**. SERP checks do not replace a fresh paid-keyword-tool refresh.
- Existing URL ownership is checked against `docs/seo-master-url-war-map.md` on current `main`.
- Full dispatch / fleet-management terms are not claimed as TLMA product terms unless the product actually supports those capabilities.

## Decision Rules

1. One primary search intent = one primary URL owner.
2. Existing specialist pages get strengthened before near-duplicate geographic/service pages are created.
3. Booking / reservation terms may map to `/booking-systems.html` only where the current custom workflow genuinely supports the requested capability.
4. Dispatch, scheduling, fleet-management and accounting terms are **capability-gated**; high CPC does not justify a false product claim.
5. Comparison pages must be neutral, source-backed, dated, and explicit about methodology and vendor bias.
6. No fabricated pricing, ratings, reviews, client results, update dates or software features.
7. `/us/` and `/uk/` folders remain provisional until the indexing bottleneck improves and each new page passes the release gate.

# Release Gate for Any New UK URL

A new production page may be released only when:

- the current indexing watch shows improved discovery of the existing architecture;
- the page has one distinct keyword owner;
- live SERP intent remains distinct from existing TLMA URLs;
- source-backed claims and dated research are ready;
- CTA is matched to the search stage;
- internal links from relevant existing hubs/pages are planned;
- schema matches the actual page type;
- no existing TLMA page is being cannibalized;
