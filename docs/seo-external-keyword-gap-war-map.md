# TLMA External Keyword Gap War Map — US + UK

**Research state:** live SERPs re-checked 2026-10-10. Volume / KD / CPC values below are the previously verified Semrush research snapshot from this project, not a same-day Semrush refresh. A dash means the metric was not verified in that snapshot and must not be guessed.

**Goal:** map every commercially useful keyword to exactly one existing or proposed URL, protect against cannibalization, and prioritize pages that can produce qualified limo / chauffeur / taxi operator leads.

## Decision Rules

1. One primary intent owner per keyword family.
2. Existing indexed money pages get strengthened before creating near-duplicate country/service pages.
3. `booking` / `reservation` terms may map to TLMA only where the current custom system genuinely supports the workflow.
4. Do **not** target `dispatch software`, `management software`, or full-fleet operations terms as a TLMA product claim unless those capabilities exist. We may publish neutral comparison / pricing content around them.
5. UK dispatch/pricing/comparison pages are approved as **strategic candidates**, but production creation remains on hold until the current indexing bottleneck shows improvement.
6. Informational comparison pages must use verifiable vendor sources, dated methodology and explicit scope; no fabricated pricing, ratings or operator results.
7. Homepage owns agency/category intent. Specialist service pages own exact service intent.

## SERP Evidence Snapshot — 2026-10-10

### US
- **Limo marketing / paid acquisition:** Limo Marketer is strongly positioned around ground-transportation Google Ads and operator growth.
- **Limo SEO:** SEOforLimos and SEO Service for Limo use dedicated niche pages and long-form local-SEO / Map-Pack / city-page messaging.
- **Limo website design:** LimoGrow is a strong niche specialist; EazyLimo also publishes booking-focused design content.
- **Limo booking software:** Limo Anywhere and LimoFlow represent the product-vendor pattern. This confirms TLMA must distinguish a custom booking system from full dispatch / fleet SaaS.
- **Google Ads:** Limo Website Marketing, Growth Choice and other PPC pages compete with specific limo-industry positioning and proof.

### UK
- **Dispatch pricing:** Taxi Elite Websites has a dedicated 2026 UK dispatch pricing page with platform-by-platform ranges and hidden-fee discussion.
- **Best dispatch software:** Taxi Web Design, Ride Dispatchers and general comparison publishers use ranked lists and methodology-led buyer guides.
- **Small fleets:** Transvoraa, Limozoft and Taxi Web Design explicitly target small fleets, confirming the specificity of this search intent.

## SERP Weaknesses TLMA Can Exploit

1. **Source transparency:** publish vendor-source links, retrieval dates and clearly label quote-only pricing instead of presenting estimates as facts.
2. **True total cost:** setup + recurring licence + driver/app + booking/transaction + payment + SMS + API/integration + migration costs.
3. **Fleet-size decisions:** 1–5, 6–20, 21–50, 50+ vehicles rather than one generic “best” list.
4. **Marketing-to-booking connection:** competitors often stop at dispatch/software. TLMA can explain acquisition → landing page → booking → admin workflow → dispatch handoff.
5. **Custom vs SaaS ownership:** data ownership, integration flexibility, UX control, recurring fees, vendor lock-in and maintenance trade-offs.
6. **No fake scoring:** any ranking methodology must be documented and evidence-backed.

## Release Gate for New UK URLs

Do not publish the UK queue simply because the keywords look attractive. Release new pages when the existing indexing watch shows Google is discovering the current architecture more reliably and each new page has:

- one distinct keyword owner;
- a real SERP gap;
- source-backed claims;
- a conversion CTA matched to the intent;
- internal links from relevant existing hubs/pages;
- schema appropriate to the actual page type;
- no overlap with an existing TLMA money page.
