# Proof publication checklist

Before changing a case from PARTIAL/HOLD to VERIFIED, record:

1. company/client identity
2. how the relationship can be verified
3. exact work performed
4. approximate dates/timeframe
5. written permission to use the company name/story publicly
6. logo/screenshot permission if used
7. source of every numerical result
8. metric definition and date range
9. baseline/comparison period where relevant
10. exact claim wording approved for publication

# Global rule
A live website, screenshot, public review count, ranking, ad-account screenshot or booking system is evidence that the artifact exists. It is **not automatically evidence that TLMA caused a particular business result**. Causation must be separately supported.
