# TLMA SEO Operating Rules

Updated: 2026-10-13

## Goal
Build The Limo Marketing Agency into a recognized limo / chauffeur / black-car growth authority, improve qualified organic traffic and leads, and move priority commercial keyword clusters toward page 1, top 3 and eventually #1 where realistically achievable.

## Hard rules

1. **One intent = one owner URL.** Each major commercial keyword cluster must have one clear primary page. Do not create overlapping pages just to target keyword variants.
2. **No over-editing after meaningful SEO changes.** After a major title/H1/internal-link/intent change, normally wait for Google recrawl plus enough settled GSC data before editing that same money page again. Default observation window: roughly 7-14 days unless a real technical error is found.
3. **Indexing before expansion.** Existing production URLs must be crawled and adopted before flooding the site with more pages. Target is 21/21 tracked URLs indexed, while recognizing Google cannot be forced to index every URL.
4. **Do not spam Request Indexing.** Submit an eligible URL once after a meaningful update or discovery problem. Repeated requests do not improve queue priority.
5. **No scaled city/airport doorway pages.** Location pages are allowed only when they satisfy distinct real search intent and contain genuinely useful, non-duplicative information.
6. **No fake proof.** Never invent testimonials, client relationships, rankings, ROAS, revenue, bookings, review counts, memberships, partnerships, awards, dates or case-study results.
7. **Permission before amplifying client proof.** A named client case study should only be promoted aggressively when the relationship, work delivered, public artifacts and permission to use the brand/results are verified.
8. **Authority over volume.** Prefer original research, verified case studies, useful tools/checklists, legitimate mentions and high-relevance links over bulk backlinks, PBNs, automated guest posts or low-quality directories.
9. **No paid memberships or email outreach unless explicitly approved by Usama.** Current default is organic/free growth only.
10. **Do not rewrite strong pages just to add keywords.** If a page already satisfies search intent and technical SEO is clean, use authority, proof, internal links, crawl adoption and original data before adding more copy.
11. **Primary ranking sequence:** discovery/indexing -> correct owner URL -> page 2/page 1 -> top 3 -> #1. Do not treat all keywords as equal priority at the same time.
12. **Primary commercial keyword order (current):**
    - limo marketing agency
    - limo seo / seo for limo companies
    - google ads for limo companies
    - limo website design
    - limo booking / reservation software
13. **Measure leads, not only rankings.** GA4 must track successful lead submissions. The primary lead event is `generate_lead`, fired only after a confirmed form submission.
14. **No causal overclaiming.** A ranking increase, review count, traffic gain or public reputation metric should not be attributed to TLMA unless evidence supports that claim.
15. **Keep brand/entity data consistent.** Use the exact entity name `The Limo Marketing Agency` and consistent service positioning across owned properties.
16. **Custom domain remains postponed until the CRM is ready unless Usama changes the decision.** Do not push a domain purchase as the immediate SEO task.

## Release gates

### Existing money pages
Do not make another major on-page change until Google has recrawled the latest version and new settled data is available, unless a technical/indexability bug exists.

### UK Taxi Dispatch System Prices page
Default release gate remains closed. Reconsider release when either:
- indexing materially improves (soft benchmark: at least 12 of 21 tracked URLs indexed with no systemic warnings), or
- a concrete earned-link / editorial opportunity justifies earlier publication.

Before release, re-verify every vendor price, remove pre-release noindex/banner, add sitemap/internal links/schema, deploy and run a live audit.

### New production pages
Do not add new production pages simply because a keyword exists. A new page requires:
- distinct intent,
- owner-URL check,
- evidence of demand/commercial value,
- non-duplicative content plan,
- internal-link plan,
- and a reason it should be released now rather than later.

## Measurement cadence

### Daily / automated
- Indexing tracker changes
- New warnings/errors

### Weekly
- Indexed count / 21
- GSC impressions and clicks
- average position
- topic-cluster position
- branded searches
- cannibalization
- GA4 sessions / organic landing pages / `generate_lead`
- meaningful new referring domains or earned mentions

### Page-level change rule
For every meaningful SEO release, keep a dated GSC annotation and compare post-change settled data against the pre-change baseline. Do not claim causation from one or two impressions.
