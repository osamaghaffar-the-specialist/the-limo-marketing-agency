# User-selected page replacement package

This package uses the files you uploaded in the current chat as the source of truth.

Important:
- `Booking system page.html` is used as `booking-systems.html`.
- `Home page.html` is used as `index.html`.
- `case-study.html` is used as `case-studies-results.html`.
- Other uploaded pages are renamed to their clean production filenames.
- The prior injected site-wide directory/footer is not used.
- Existing `thank-you.html` and the published Google Ads resource article are retained because they do not conflict with an uploaded replacement page.

Extract this ZIP directly into the existing local repository folder with `-Force`, then commit and push.
